Python Docs Assistant (RAG)

A chatbot that answers Python questions only from the official docs - and shows which page each answer came from.

  • LangChain
  • ChromaDB
  • Gemini
  • text-embedding-004
  • Streamlit
  • BeautifulSoup
  • pytest

Team project.

Problem

General-purpose LLMs answer Python questions confidently, including when they're wrong or out of date, and give you nothing to check against. The goal: answer from the documentation itself, show the passages used, and decline when the docs don't cover the question.

Approach / architecture

  1. ScrapeBeautifulSoup collects the Python tutorial, 33 standard-library module pages, the language reference, and asyncio docs from docs.python.org, stripping navigation and scripts, rate-limited to one request per second.
  2. ChunkRecursive splitting into 1,000-character chunks with 200 characters of overlap, keeping source URL, title, and position as metadata.
  3. Embed, with a cacheGoogle text-embedding-004 (768-dim) in batches of 100, with retries and exponential backoff. Vectors are cached on disk by content hash, so re-indexing only pays for new chunks.
  4. StoreA persistent ChromaDB collection using cosine distance.
  5. RetrieveNormalize and embed the query, over-fetch 2× the requested top-k (default 5), filter by a similarity threshold, keep the best k. Optional Maximal Marginal Relevance reduces near-duplicate chunks.
  6. Prompt and generateA system prompt restricts answers to the supplied context and requires citations. Follow-ups include recent conversation history. Gemini generates at temperature 0.3.
  7. UIA Streamlit chat with expandable sources and relevance scores, sliders for temperature and number of sources, and one-click index rebuilds.

Key decisions & tradeoffs

Decline instead of guess

When no chunk clears the similarity threshold, the system returns a "not in the documentation" response and skips the LLM call entirely. That removes the main source of hallucination and saves an API call, at the cost of refusing some borderline questions.

Tuning the relevance threshold

The threshold started at 0.7 and was lowered to 0.5 after it filtered out relevant chunks. That's a deliberate recall-over-precision choice, since the prompt instructs the model to say so whenever the supplied context doesn't contain the answer.

Resilience to API changes

If the configured Gemini model is unavailable, the chain falls back through a list of alternative models instead of failing. Embedding calls retry with exponential backoff, and cached vectors mean a rebuild doesn't re-embed unchanged text.

Modular pipeline

Scraper, chunker, embedder, vector store, retriever, prompts, and chain are separate modules, so each can be tested and swapped on its own. The test suite covers each stage plus an end-to-end flow.
