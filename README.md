# SaiSridharParimi.github.io

Portfolio site served at https://sridharp.me (GitHub Pages, custom domain via `CNAME`).

Plain HTML/CSS, no build step. Edit the files and push.

- `index.html`: intro and project list
- `projects/*.html`: one page per project
- `css/style.css`: all styles; light/dark tokens at the top
- `js/theme.js`: optional dark-mode toggle (the site works without JS)
- `assets/`: PDFs and images (paper goes at `assets/multi-model-summarization.pdf`)
